in the "handleAdd" function

        Task<Void> task = new Task<Void>() {
            @Override
            protected Void call() throws Exception {
                try(Connection conn = DatabaseManager.getConnection()){
                    Main.addPatient(conn,name,address,email,phone,doctor);
                }
                return null;
            }
        };

explination :

a)javafx.concurrent.Task is a class used to run time consuming operations in a background thread to keep the Ui from freezing
when we update,add or search a patient

b)Task<void> produces no value when it finishes, we dont need it to return a value because it's job is to connect to the add,search or update
method from the main class which are then saved in the database

c)new thread<void> is used to override "protected Void call()" because abtract methods like "call" provide no implementation in a base class
(it has no node, parent or control parent class to inherent or reuse)

d)call() itself is task equivalent to run() that can throw return values and checked exceptions.

e)try(Connect conn = DriverManager.getConnection()) is used to retrieve resources from the intended main file be it add,update or search
DriverManager calls the JDBC connection (Database manager exists in file but main needs some reconfiguring to make it work as it should)

f) Main.addPatient(...) is our method we connect to for our button
